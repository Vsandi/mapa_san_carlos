# 🗺️ Mapa Interactivo de San Carlos, Alajuela
## 📋 Descripción
Mapa web interactivo del cantón de San Carlos, Alajuela (Costa Rica), que integra información geográfica de múltiples fuentes. El proyecto incluye relieve, hidrografía, división administrativa, infraestructura vial, servicios públicos y puntos de interés.

## ✨ Características Principales
* Modelo de Elevación Digital (DEM) con colores hipsométricos
* Relieve sombreado (hillshade) para realce topográfico
* 18 capas temáticas incluyendo servicios de salud, educación, comercio y áreas verdes
* 9 niveles de zoom (8-16) con jerarquía visual optimizada
* Diseño responsivo compatible con dispositivos móviles
* Leyenda interactiva con información detallada

## 🛠️ Tecnologías Utilizadas
* GDAL - Generación de DEM y procesamiento raster
* TileMill + CartoCSS - Diseño cartográfico y estilizado
* Leaflet.js - Visualización web interactiva
* MapWindow & QGIS - Procesamiento de datos vectoriales
* GitHub Pages - Hosting y publicación

## 📊 Fuentes de Datos
* Instituto Geográfico Nacional (IGN) Costa Rica - Capas base nacionales
* OpenStreetMap - Datos de servicios y áreas verdes
* Datos del curso - Información geográfica complementaria
